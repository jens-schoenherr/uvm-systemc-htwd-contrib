# uvm-systemc-htwd-contrib
Usefull things for UVM-SystemC

## FC4SC
### User's guide

FC4SC is a library to measure functional coverage during a simulation in SystemC.
The current version is freely available from Accellera: https://github.com/accellera-official/fc4sc.
The documentation of the original version of FC4SC provided by Amiq (https://github.com/amiq-consulting/fc4sc) is incomplete and does not include changes implemented in the meantime.
The User's guide provided here fits to the current version of FC4SC as provided by Accellera.
It includes a short tutorial and an almost complete description of the API provided by FC4SC.

### HTML-GUI

The FC4SC version provided by Amiq contains a HTML+JS-based tool to show UCIS-XML-files in a browser.
Since the XML files generated by the Accellera version differ from the ones generated by the Amiq version, the HTML-GUI of Amiq does not show anything.
A patch of the Amiq version is provided here that works with XML files produced by the Accellera version.

### Merge-tool

For the same reasons as for the HTML-GUI the Python-bases tool for merging two or more UCIS-XML-files does not work.
A patch of the Amiq version is provided here that works with XML files produced by the Accellera version.
